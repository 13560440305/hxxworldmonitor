## 1. 总览：计划功能全景

按产品路线整理的**计划实现全集**（含已做与未做）：

| 域 | 计划能力 |
|----|----------|
| **仪表盘 OSINT** | 多变体地图+面板、多语言 UI、实时图层、AI 简报（**仅 B/S**） |
| **实时 API** | sebuf 领域服务、RSS 代理、Relay（AIS/飞机/Telegram） |
| **Platform 底座** | PG + 迁移、Docker 依赖、Platform API、日志、Admin |
| **新闻 Monitor** | RSS 入库、PG digest、分类去重、冷归档 |
| **邮件订阅** | 预设套餐、匹配投递、多语言投递、Open 订阅 API、用户自助页 |
| **AI** | Groq/OpenRouter/Ollama、按需 Brief、定时 Brief、翻译缓存 |
| **Research** | Embedding、monitor/entities API、前端 Research 产品、定期报告 |
| **企业图谱** | CN 巨潮采集、关系抽取、图谱 UI；美/港/欧采集；图谱深化 / Neo4j |
| **Job 体系** | Scheduler/Executor、Admin 入队、DAG（如行情→图谱） |
| **数据源治理** | 凭证 DB 化、handler 全量读 DB、RSS 目录 DB 化、Relay 入 DB |
| **Enterprise** | Agent、Webhook、IM、公开企业 API、计费套餐 |
| **工程迁徙** | 主前端进 `apps/frontend`、sebuf 抽包、删除 shim |

## 5. 建议验收顺序（本地）

1. `npm run platform:up`（或本机 PG）→ `platform:db:migrate`  
2. `platform:admin:init` → `admin:dev` 配 HXXBOT / 数据源  
3. `platform:scheduler` + `platform:executor`（或 `platform:producer`）  
4. `platform:api` + `npm run dev`  
5. 验证：健康检查、RSS 入库、订阅试投、（可选）巨潮绑定后手动入队披露 Job  

运维细节：[deploy/README.md](../deploy/README.md)。
